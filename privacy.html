DBank — Branch Performance App · berlaku sejak Oktober 2026

DBank adalah aplikasi internal untuk memantau performa cabang (akuisisi produk, layanan, leads, dan pipeline dana). Halaman ini menjelaskan data apa yang diproses dan bagaimana data itu dipakai.

Data yang dikumpulkan

NIP pengguna, alamat email (untuk reset password), password dalam bentuk hash SHA-256 (password asli tidak pernah disimpan), serta data kerja yang diinput pengguna: laporan akuisisi, data layanan, penilaian, leads, pipeline dana, dan pengumuman.

Tempat penyimpanan

Data disimpan di Google Sheets milik pengelola cabang melalui Google Apps Script. Perangkat pengguna menyimpan salinan sementara (cache) agar aplikasi tetap tampil saat jaringan lambat. Data tidak dijual dan tidak dibagikan ke pihak ketiga untuk iklan.

Penggunaan data

Data hanya dipakai untuk menampilkan dashboard, leaderboard, laporan PDF/Excel, dan mengirim kode reset password ke email pengguna.

Hak pengguna

Pengguna dapat meminta koreksi atau penghapusan data kepada Admin aplikasi di cabang. Keluar (logout) menghapus sesi di perangkat.
